# AirBallonGame

Это игра на платформе WinForms, где два игрока управляют воздушными шарами с помощью клавиш на клавиатуре, пытаясь избежать столкновения с границами и подняться до верхней части экрана.

## Описание

В игре участвуют два игрока. Каждый игрок управляет воздушным шаром с помощью одной группы клавиш:
- Первый игрок использует клавиши: `QWERTASDFZXCV`.
- Второй игрок использует клавиши: `YUIOPGHJKLBNM`.

Каждому игроку на экране будет отображаться случайная клавиша. Игрок должен нажать эту клавишу на клавиатуре, чтобы заставить свой воздушный шар прыгать вверх. Если игрок не успевает нажать клавишу вовремя или сталкивается с границей экрана, игра заканчивается.

## Инструкция

1. **Запуск игры:**
   - При запуске игры появится окно с вопросом, хотите ли вы начать игру. Если игрок нажимает "Yes", игра начинается.
   
2. **Управление:**
   - Первый игрок управляет своим шаром с помощью клавиш `QWERTASDFZXCV`.
   - Второй игрок управляет своим шаром с помощью клавиш `YUIOPGHJKLBNM`.

3. **Как играть:**
   - На экране появится случайная клавиша для каждого игрока.
   - Игроки должны нажать соответствующую клавишу на клавиатуре, чтобы их воздушный шар прыгнул вверх.
   - Игра продолжается до тех пор, пока один из игроков не столкнется с границей или не проиграет.
   
4. **Конец игры:**
   - Когда один из игроков столкнется с границей, игра завершится. Появится окно с предложением начать новую игру или выйти.

## Функциональность

- **Два игрока:** Игра поддерживает двух игроков, каждый из которых управляет своим воздушным шаром.
- **Случайные клавиши:** Для каждого игрока генерируется случайная клавиша, которую необходимо нажать.
- **Динамическое управление:** Игроки могут нажимать клавиши для движения вверх, чтобы избежать столкновения с границами.
- **Конец игры:** Игра завершится, если один из игроков столкнется с границей.
